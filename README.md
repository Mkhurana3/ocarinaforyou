# ocarinaforyou

Ocarina of Time on a Mac, using nxnative.

This is a fork of https://github.com/seedds/nxnative. The notes, settings and test scripts for The Legend of Zelda: Ocarina of Time (0400486024DEC000, v131072) are in [oot/](oot/README.md).

The emulator code itself is unchanged from upstream. For the project, its docs and everything else, see https://github.com/seedds/nxnative.

This repo contains no game files and no keys.
